# Навык: Suveren — Аудит сайта на соответствие законам РФ

Навык проводит глубокий пассивный аудит сайта и компании на соответствие требованиям российского законодательства, проверяет инфраструктуру на зависимость от зарубежных провайдеров и оценивает юридические риски.

---

## 🛠️ Доступные команды CLI

```bash
# 1. Экспресс-сканирование сайта (быстро, по DNS и сетевым отпечаткам)
suveren scan <домен>

# 2. Полный аудит с открытием в реальном браузере (РЕКОМЕНДУЕТСЯ)
# Парсит до 6 ключевых страниц, проверяет формы ввода, чекбоксы, куки и внешние JS-скрипты
suveren scan <домен> --browser

# 3. Выгрузка чистого отчета в формате Markdown
suveren report <домен> --browser -f markdown -o audit_<домен>.md

# 4. Выгрузка в HTML (для передачи заказчику или руководству)
suveren report <домен> --browser -f html -o audit_<домен>.html

# 5. Диагностика источников и реестров
suveren doctor
```

---

## 📋 Порядок проведения аудита

### Шаг 1. Запуск сканирования
При запросе на проверку сайта всегда запускай:
```bash
suveren scan <домен> --browser
```
Если сайт блокирует headless-браузер или проверка падает по таймауту, сделай откат на:
```bash
suveren scan <домен>
```

### Шаг 2. Разбор результатов (4 ключевых блока)

1. **Технологический суверенитет и санкционные риски (Оценка от A до F):**
   * **DNS-серверы:** российские (Яндекс, Selectel, Beget, REG.RU) или иностранные (Cloudflare, AWS, Google).
   * **Хостинг / Сервер:** находится ли IP физически в РФ (требование ч. 5 ст. 18 152-ФЗ о первичной локализации баз данных).
   * **Корпоративная почта (MX):** российская (Яндекс 360, VK WorkSpace) или зарубежная (Google Workspace, Microsoft 365).
   * **Внешние фронтенд-скрипты и трекеры:** Google Analytics, Google Fonts, ReCaptcha, YouTube-эмбеды (риск утечки IP и персональных данных за границу).

2. **Соответствие 152-ФЗ «О персональных данных»:**
   * **Политика конфиденциальности:** найдена ли ссылка на документ в подвале/меню.
   * **Формы сбора данных:** есть ли текст согласия под формами обратной связи, заявок, регистрации.
   * **Согласие на Cookies:** есть ли уведомление/баннер для посетителей.
   * **Реестр операторов ПДн (РКН):** состоит ли юрлицо в официальном реестре операторов (`pd.rkn.gov.ru`).

3. **Блокировки Роскомнадзора:**
   * Проверка домена и IP-адресов по единому реестру запрещенных сайтов РКН.
   * Доступность через фильтрацию ТСПУ / DoH.

4. **Юридическая чистота (ФНС и Санкции):**
   * Данные компании из ЕГРЮЛ/ЕГРИП.
   * Проверка компании и её руководителя по санкционным спискам США (OFAC SDN), ЕС и Великобритании.
